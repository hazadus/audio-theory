# Чеклист материала

Применять вместе с [правилами](rules.md), перед передачей автору и после доработок. Для каждого пункта записать результат: «пройдено» с свидетельством, «неприменимо» с причиной или «не выполнено». Невыполненная обязательная проверка блокирует завершение; неприменимость не заменяет проверку. Числовые рекомендации оцениваются редакционно и не блокируют материал. Пример заполнения — [проверка шаблона](template-review.md).

## Выбор и объяснение

- [ ] Изучены существующие статьи, [темы](../topics.md), связи и глоссарий. Выбор дополнения или новой статьи обоснован, дублирования нет.
- [ ] Объяснение соответствует уточнениям пользователя, по умолчанию начинается с основ; понятия и предварительные знания позволяют читать статью самостоятельно.
- [ ] Русский текст и английское название основного термина при первом упоминании; термины, обозначения и единицы последовательны.
- [ ] Просмотрен [список рекомендуемых источников](sources.md); найденные полезные и изученные источники добавлены с описанием тем.
- [ ] Прочитаны подтверждающие источники, проверены факты, условия, определения, формулы, расчёты и граничные случаи; данные и заимствования имеют источник и допустимое использование.
- [ ] Весь изменённый текст, подписи и определения проверены по актуальному [tropes.md](https://tropes.fyi/tropes-md); русскоязычные шаблоны исправлены без потери точности.
- [ ] Рекомендации по тегам, врезкам и длине кода рассмотрены; превышение не превращено в запрет. Необязательные разделы и интерактивность добавлены по смыслу.

## Контент и связи

- [ ] MDX и импорты `@/`; обязательные `slug`, `title`, `question`, `topic`, `tags`, `related` заполнены по контракту. Группа существует, новый `slug` уникален, `readingMinutes` при наличии — положительное целое. `updated` отсутствует.
- [ ] Источники в `## Источники {#sources}` содержат хотя бы одну проверенную ссылку. Внешние страницы открыты отдельно: сборка их не проверяет.
- [ ] Связи имеют `label`, `description`, `target`; внутренние статьи, якоря и ресурсы существуют, для отсутствующей темы выбрана соответствующая Википедия. Нет глобального порядка «предыдущая / следующая».
- [ ] Якоря английские и стабильные, H2/H3 образуют оглавление, H4 не включён; `id` уникальны. Логические URL не содержат префикс; в HTML `base` добавлен один раз.
- [ ] Используемые компоненты существуют и соответствуют текущему API. Номера рисунков/визуализаций, таблиц и формул идут по своим последовательностям, ссылки совпадают.
- [ ] Новые обозначения формул пояснены с единицами; MathML доступен, длинная формула прокручивается внутри блока.
- [ ] Рисунки имеют название, описание и содержательную подпись; таблицы — `caption`, заголовки и `scope`; серии различимы без опоры только на цвет, оси и единицы читаются.
- [ ] Врезки различимы текстом и оформлением, ошибка содержит «Неверно / Верно», самопроверка раскрывается клавиатурой и без JS.
- [ ] Каждый листинг имеет язык; пример проверен, подсветка работает в обеих темах без JS, копируется весь исходный текст. Отказ clipboard не сообщает успех и позволяет выделить код вручную.
- [ ] Глоссарий и `Term` используют одну запись с коротким определением без HTML и существующей целью; подсказка доступна фокусом и касанием, закрывается по Esc, основная ссылка работает.

## Проверки сайта

- [ ] Применимые `just fmt`, `npm run fmt:check`, `just lint`, `just typecheck`, `just test` выполнены; новая предметная логика подтверждена осмысленными unit-тестами.
- [ ] `just build` прошёл (до коммита новой статьи — с `ALLOW_DRAFT_ARTICLES=1`): метаданные, формулы, контент, внутренние страницы/якоря/ресурсы и Pagefind. «Черновик» виден только в локальном режиме; публикуемая сборка использует настоящую Git-дату и полную историю.
- [ ] При изменении MDX/формул выполнен `npm run test:mdx`, схемы/маршрутов — `npm run test:articles`; при изменении критичного пути, доступности или адресов — полный `just test-e2e`, включая корень и префикс. Поиск проверен по настоящему индексу, когда затронута индексация.
- [ ] Локальное чтение в обеих темах на 390 и 1440 px и без JS проверено; широкие блоки также на 320 px. Страница не прокручивается горизонтально; ссылки и ресурсы учитывают `base`.
- [ ] Для изменённого UI проверены состояния, клавиатура, фокус, увеличение текста/масштаба и границы 599/600, 1023/1024, 1279/1280 px из дизайн-системы. Создание снимков сопровождается просмотром.

## Визуализация и аудио — если добавлены или изменены

- [ ] Численные и граничные случаи проверены; график, параметры, легенда, подпись, статус и звук соответствуют одной модели; сброс полный.
- [ ] Без JS, при загрузке и ошибке остаётся корректный статичный рисунок; контролы отражают готовность. Управление доступно клавиатурой и касанием.
- [ ] Звук запускается действием пользователя, имеет предупреждение перед чистыми тонами, начальные 30 % и плавные края; пауза, остановка, перемотка, громкость и mute проверены, при уходе со страницы звук прекращается.
- [ ] Ошибка Web Audio объясняется и не ломает график; клавиши плеера не мешают полям и ползункам. Автотесты, ручное прослушивание и настоящий Safari на Mac/iPhone проверены и записаны отдельно.

## Авторское одобрение и завершение

- [ ] Автор получил локальные URL актуального текста, прочитал материал; доработки внесены и повторно проверены. Собственный сервер оставлен на время чтения и затем корректно остановлен.
- [ ] Получено явное одобрение текущих статей, правок текста, определений и «О проекте» до включения в коммит. При отсутствии одобрения материалы остаются вне коммита.
- [ ] Связанные документы обновлены, обязательных незавершённых проверок нет. Коммит выполняется вызывающим процессом по `commit`, без автоматического пуша для обычной локальной задачи.
- [ ] При порученной публикации выполнен процесс [deploy.md](../deploy.md), проверены CI, деплой нужного SHA и production; черновики и служебные образцы не опубликованы.
