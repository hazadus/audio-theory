# Проверка служебного шаблона

Проверен [article-template.mdx](article-template.mdx) по [чеклисту](checklist.md) при подготовке общих правил. Это учебный образец разметки вне публичной коллекции; результат не разрешает публиковать его как статью. Команды воспроизведения — в [обзоре](../overview.md#общие-правила-подготовки-материалов).

## Выбор и объяснение

| Пункт чеклиста | Результат и свидетельство |
| --- | --- |
| Изучение материалов и выбор | Пройдено: публичных статей пока нет; изучены темы первого выпуска и служебные фикстуры. Образец ограничен оформлением и не заменяет будущую статью о дискретизации. |
| Уровень и самостоятельность | Пройдено: исходные понятия введены до формулы, предварительные знания не требуются. |
| Язык и термины | Пройдено: русский текст, sample rate и sampling period при первом упоминании; единицы Гц, с и мс согласованы. |
| Список рекомендуемых источников | Пройдено: книга Smith добавлена по рекомендации автора, указаны прочитанные разделы; правила предусматривают пополнение списка. |
| Источники, факты и расчёты | Пройдено: открыта глава Smith о дискретизации. Независимо пересчитаны `1 / 8000 = 0,000125` с и `1 / 16000 = 0,0000625` с, переход в мс и удвоение частоты. Указана область: равномерная дискретизация при положительной частоте. Заимствованных рисунков и данных нет. |
| Редактура по tropes.md | Пройдено: прочитан актуальный каталог, проверены вводный текст, определения, пример, вопрос и ответ; технические обозначения сохранены. |
| Рекомендации и необязательные блоки | Пройдено: числовые лимиты в правилах и чеклисте явно рекомендательные; шаблон не требует всех компонентов. |

## Контент и связи

| Пункт чеклиста | Результат и свидетельство |
| --- | --- |
| MDX, импорты, frontmatter | Пройдено: сборка читает шаблон через штатную коллекцию; обязательные поля валидны, `updated` и ручного времени чтения нет, выводится 1 минута. |
| Раздел источников | Пройдено: `sources` с проверенной внешней ссылкой на конкретный раздел книги. |
| Связи | Пройдено: `related` содержит название, пояснение и ссылку на Википедию для ещё отсутствующей своей статьи; предварительные знания опущены. |
| Якоря и base | Пройдено: `concept`, `calculation`, `sources` входят в оглавление, ссылка на `eq-sample-period` существует; сборка под `/audio-theory/` проходит проверку артефакта. |
| API и нумерация | Пройдено: реальные `Callout`, `Equation`, `SelfCheck`; единственная нумерованная формула имеет номер 1. |
| Формулы | Пройдено: KaTeX создал MathML, символы пояснены с единицами, формула читается на 390 px без расширения страницы. Длинного выражения в образце нет. |
| Рисунки и таблицы | Неприменимо: шаблон их не содержит. Требования к подписям, описаниям, осям, caption и scope остаются в чеклисте. |
| Врезка и самопроверка | Пройдено: определение имеет текстовую метку; ответ раскрывается, в том числе без JS. Врезки ошибки нет, её контракт записан в правилах. |
| Листинги | Неприменимо: кода в шаблоне нет; требования к языку, темам и clipboard перечислены в чеклисте. |
| Глоссарий и Term | Неприменимо: записей и подсказок не добавлялось; единый источник и доступность предусмотрены правилами. |

## Проверки сайта

| Пункт чеклиста | Результат и свидетельство |
| --- | --- |
| Форматирование, линтер, типы, unit | Пройдено: `just fmt`, `npm run fmt:check`, `just lint`, `just typecheck`, `just test` — 273 теста в 20 файлах. Новая предметная логика не добавлялась. |
| Сборка и дата | Пройдено: отдельная сборка шаблона с `ARTICLES_DIR=./docs/authoring` и `ALLOW_DRAFT_ARTICLES=1` в `.e2e/authoring-template/`; «Черновик» подтверждён в браузере. Обычный `just build` без переменных создаёт только начальную страницу, шаблона в публичной сборке нет. |
| Специализированные проверки | Неприменимо: обработчики MDX, схемы, маршруты, индексация и пользовательские пути не менялись; полный E2E, `test:mdx`, `test:articles` не запускались. Их условия перечислены в чеклисте. |
| Локальное чтение | Пройдено: Chromium, 390/1440 px, светлая/тёмная тема; текст, MathML, якорь, ответ и отсутствие горизонтальной прокрутки проверены. На 390 px проверено чтение и раскрытие без JS; снимки обеих тем просмотрены. Широких блоков нет. |
| Изменённое UI и границы | Неприменимо: компоненты и стили приложения не изменены; проверка шаблона использует существующий layout. Полный набор границ и состояний сохраняется для задач UI. |

Все пункты раздела «Визуализация и аудио» неприменимы: в образце нет графика, интерактивных параметров или звука. Чеклист сохраняет отдельные требования к модели, fallback, плееру, навигации, ручному прослушиванию и настоящему Safari на Mac/iPhone.

## Авторское одобрение и завершение

| Пункт чеклиста | Результат и свидетельство |
| --- | --- |
| Передача локального результата | Пройдено: пользователю переданы документы и локальный URL шаблона; все 15 незакоммиченных файлов просмотрены в Crit. |
| Явное одобрение до коммита | Пройдено: Crit завершён с `approved: true`, без замечаний. Ограничение пользователя «не коммитить до моей проверки» соблюдено. Одобрение будущих статей этим образцом не подразумевается. |
| Документы и завершение процесса | Пройдено: документы обновлены. Шесть скиллов имеют ссылки, разрешающиеся в один набор общих файлов, и сохраняют авторскую проверку и ограничения пуша. Codex-скиллы прошли `quick_validate.py`; YAML всех шести проверен, штатный `argument-hint` Claude сохранён. |
| Публикация | Неприменимо: задача локальная, публикация не поручена, шаблон не попадает в `dist/`. |

Проверка подтверждает применение чеклиста к образцу и покрытие требований спецификации; она не заменяет будущие проверки компонентов, подготовку реальных статей или проверку обнаружения `write-article` в обоих агентах из следующего пункта плана.
