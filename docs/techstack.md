# Технологический стек

Документ содержит выбранные и рассматриваемые технологии с их статусом. Требования к проекту находятся в [spec.md](spec.md), открытые вопросы — в [questions.md](questions.md).

## Поиск: Pagefind

**Статус: рассматриваемый вариант; окончательное решение не принято.**

[Pagefind](https://pagefind.app/) — библиотека полнотекстового поиска для статических сайтов.

### Как работает

1. После сборки сайта Pagefind индексирует содержимое готовых HTML-страниц.
2. Файлы индекса и код поиска публикуются вместе с сайтом.
3. Браузер загружает нужные части индекса и выполняет поиск без серверной части.
4. Индекс пересоздаётся при каждой сборке перед публикацией сайта.

Описание процесса: [документация Pagefind](https://pagefind.app/docs/).

### Почему рассматриваем

- Подходит для статического сайта без отдельного поискового сервиса.
- Есть готовый интерфейс поиска и возможность показывать результаты по разделам страниц.
- Поддерживает русский интерфейс и обработку основ русских слов для поиска по словоформам: [поддержка языков](https://pagefind.app/docs/multilingual/).

При реализации нужно проверить поиск по русскому тексту и английским терминам на примерах наших статей, а также интеграцию с генератором сайта и оформление поиска в светлой и тёмной темах. Интерфейс — собственный попап поверх JS API Pagefind, по [дизайн-системе](design-system.md#поиск).

## Формулы: KaTeX

**Статус: выбран.** Формулы рендерятся при сборке, со шрифтами KaTeX и доступным математическим представлением. Кириллица внутри `\text{}` оформляется шрифтом статьи.

## Статический генератор: Astro

**Статус: предварительный выбор; окончательное решение не принято.** Макеты предлагают Astro. Дизайн-система задаёт CSS-токены и семантическую разметку независимо от генератора.

## Визуальные ресурсы

**Статус: выбраны в составе дизайна.** Literata, Golos Text и JetBrains Mono размещаются на сайте в WOFF2 с кириллицей и латиницей; иконки — Lucide. Шрифты формул поставляются с KaTeX. При подключении ресурсов сохраняются их лицензии.

## Аудиопримеры

**Статус: выбран подход.** Синтетические сигналы создаются через Web Audio в браузере; файлы используются для записей. Запуск — только по действию пользователя.
