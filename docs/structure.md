# Целевая структура проекта

Это целевая структура проекта, которой пока нет. Сейчас в репозитории находятся документация и HTML-макеты. Файлы и компоненты из схемы ниже добавляются по мере выполнения [плана реализации](plan.md), без пустых заготовок для будущих возможностей. Контракты данных и учебных компонентов описаны в [спецификации](spec.md#данные-материалов-и-учебные-компоненты).

```text
.agents/skills/write-article/SKILL.md   # Вход в скилл Codex
.claude/skills/write-article/SKILL.md   # Вход в скилл Claude Code
.github/workflows/pages.yml           # Проверки, сборка и деплой
docs/authoring/                       # Общие правила и шаблон статьи
src/content/articles/                # Пять статей в MDX и будущие материалы
src/content.config.ts                # Схема коллекции статей
src/data/topics.ts                   # Четыре тематические группы
src/data/glossary.json                # Единый источник определений
src/components/                      # Каркас, учебные блоки, поиск и визуализация
src/layouts/                         # Общая страница и страница статьи
src/lib/                             # Метаданные, ссылки, расчёты и Web Audio
src/pages/                           # Статические маршруты Astro
src/styles/                          # Токены, базовые стили и оформление статьи
src/site.config.ts                   # Адрес сайта, репозитория и базовый путь
public/fonts/                        # Локальные WOFF2 и лицензии
scripts/                             # Проверка контента и собранного сайта
tests/                               # Unit-тесты и браузерные сценарии
astro.config.mjs
justfile
```

Основной HTML создаётся при сборке. Клиентский JavaScript подключается к поиску, теме, навигации, фильтрам и интерактивному примеру по необходимости; полноценный клиентский фреймворк для первого выпуска не требуется. Макеты служат визуальными образцами: их демонстрационный рантайм не переносится в приложение.
