# Открытые вопросы

Согласованные требования к материалам зафиксированы в [spec.md](spec.md), первые темы — в [topics.md](topics.md). Ниже находятся вопросы, которые ещё обсуждаются.

Для составления плана первого выпуска обязательные решения согласованы. Схемы данных, параметры компонентов, пути и способ подключения общего набора правил скиллов определяются в плане реализации.

## Аудиоалгоритмы и примеры кода

Примеры C++/JUCE добавляются по мере необходимости и не входят в обязательный объём первого выпуска. Вопросы ниже уточняются при подготовке таких материалов и не препятствуют составлению плана первого выпуска.

- В каких статьях добавлять разбор алгоритмов и примеры на C++/JUCE: по отдельному запросу или по усмотрению агента, когда это помогает понять тему?
- Какой формат примеров нужен: короткие фрагменты в статьях, отдельные собираемые проекты или их сочетание? Предложение описано в [idea.md](idea.md#аудиоалгоритмы-и-практика-с-juce).

Главная с тематическими группами, отдельный список материалов, глоссарий и правила метаданных согласованы; требования перенесены в [spec.md](spec.md). Правила UI и расхождения внутри макетов описаны в [design-system.md](design-system.md).

Новые открытые вопросы добавляем в этот файл по мере обсуждения.
