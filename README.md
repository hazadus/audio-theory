# Теория аудио

Личный учебник по теории аудио и цифровой обработке звука: самостоятельные статьи, визуализации и интерактивные примеры. Материалы пишутся на русском с английскими названиями основных терминов. Статический сайт предназначен для публикации на GitHub Pages.

## Документация

- [Идея проекта](./docs/idea.md) — замысел и предложения для развития.
- [Спецификация](./docs/spec.md) — согласованные требования, контракты данных и правила публикации.
  - [Открытые вопросы](./docs/questions.md) — решения, которые предстоит обсудить.
- [Темы материалов](./docs/topics.md) — состав первого выпуска и задачи статей.
- [Дизайн-система](./docs/design-system.md) — оформление, адаптация и поведение UI; [HTML-макеты](./docs/design/) — визуальные образцы.
- [Технический стек](./docs/techstack.md) — выбранные технологии и статус вариантов.
- [Структура проекта](./docs/structure.md) — целевые каталоги, которых пока нет.
- [Стайлгайд](./docs/styleguide.md) — соглашения по коду, языку, командам и коммитам.
- [План реализации](./docs/plan.md) — этапы и критерии готовности.
- [Задачи](./docs/todos.md) — список задач для реализации.

## Разработка

Сейчас в репозитории есть документация и макеты; приложение и команды запуска ещё предстоит настроить.

Новые открытые вопросы записывайте в `docs/questions.md`, согласованные требования — в `docs/spec.md`. Статьи проверяются автором на локальном сайте и публикуются только после одобрения.

## Скиллы агентов

| Задача | Codex | Claude Code |
| --- | --- | --- |
| Проверить изменения и создать логические коммиты | `$commit` | `/commit` |
| Выполнить указанный пункт `docs/todos.md`, проверить и закоммитить | `$execute 4` | `/execute 4` |
| Выполнить GitHub issue, дать результат на проверку и отчитаться в issue | `$issue 26` | `/issue 26` |

Скиллы учитывают наличие команд и тестов на текущем этапе разработки. Материалы включаются в коммит только после личной проверки и одобрения автором; обычные локальные задачи не запускают пуш. При порученной публикации проверяются CI, деплой и опубликованный сайт. Общий скилл подготовки статей `write-article` и правила `docs/authoring/` ещё предстоит создать по [плану](./docs/plan.md#4-подготовить-общий-скилл-и-первые-тексты).
