# Теория аудио

Личный учебник по теории аудио и цифровой обработке звука в виде статического сайта. Агенты помогают создавать и дополнять статьи, визуализации и интерактивные примеры. Материалы пишутся на русском языке с английскими названиями основных терминов в скобках. Публикация — на GitHub Pages.

## Документация

- [docs/spec.md](docs/spec.md) — согласованные требования к сайту, материалам и работе агента.
- [docs/styleguide.md](docs/styleguide.md) — общие соглашения о коде, языке, конфигурации и коммитах.
- [docs/idea.md](docs/idea.md) — замысел проекта и предложения для обсуждения.
- [docs/topics.md](docs/topics.md) — темы материалов; тема не обязательно соответствует отдельной статье.
- [docs/techstack.md](docs/techstack.md) — рассматриваемые технологии и статус их выбора.
- [docs/questions.md](docs/questions.md) — открытые вопросы.

При работе опирайся на спецификацию. Новые открытые вопросы записывай в `docs/questions.md`, а согласованные требования — в `docs/spec.md`. Учитывай статус технологий: рассматриваемый вариант не является окончательно выбранным.
