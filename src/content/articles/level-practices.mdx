<Term id="vu-meter" firstMention>VU-метр</Term> создавали для аналогового тракта: 0 VU на его шкале — рабочий уровень, а выше остаётся запас, который лента и усилители переносят без резкого искажения. В цифровой записи предел 0 <Term id="dbfs" firstMention>dBFS</Term> жёсткий, и привычки аналоговой студии перестали работать. Статья описывает индикатор перегрузки <Term id="over" firstMention>OVER</Term>, соглашения о том, сколько dBFS соответствует 0 VU, и <Term id="k-system" firstMention>K-систему</Term> Боба Каца (Bob Katz), которая привязывает шкалу измерителя к <Term id="loudness" firstMention>громкости</Term> в контрольной комнате. Значительная часть фактов взята из статей Каца «Level Practices» на сайте его студии Digido; там, где он выражает собственную позицию, это отмечено.

## Цифровая шкала без запаса {#no-headroom}

<MarginNote items={[
  { label: 'Уровень сигнала → Полная шкала: dBFS', description: 'Что такое 0 dBFS и почему значения за ним срезаются.', target: { article: 'signal-level', anchor: 'dbfs' } },
]}>

В аналоговой студии магнитная лента насыщается постепенно: на громких пиках она добавляет вторую и третью гармоники, а не срезает вершину волны. Кац пишет, что из-за этого пики на ленте поднимались над 0 VU примерно на 14 дБ, не больше, а усилители с пределом на 16 дБ выше 0 VU оставляли им место ([Katz, Level Practices, ч. 1](#sources)). У цифрового формата такого мягкого участка нет: всё, что выше <Term id="full-scale" firstMention>полной шкалы</Term>, превращается в <Term id="clipping" firstMention>клиппинг</Term>.

</MarginNote>

Различаются и сами записи. Разность пикового и среднего уровня, <Term id="crest-factor" firstMention>пик-фактор</Term>, у аналоговой записи по Кацу около 14 дБ, а у цифровой записи без компрессии — до 20 дБ ([Katz, Level Practices, ч. 1](#sources)). Если выровнять обе записи по пику, средний уровень находится из [формулы (1)](#eq-average-level).

<Equation id="eq-average-level" number={1}>

$$
L_\text{ср} = L_\text{пик} - C
$$

<Fragment slot="symbols">
  <dt>$L_\text{ср}$</dt><dd>средний уровень записи, dBFS;</dd>
  <dt>$L_\text{пик}$</dt><dd>пиковый уровень, dBFS;</dd>
  <dt>$C$</dt><dd>пик-фактор, дБ.</dd>
</Fragment>

</Equation>

При пике 0 dBFS аналоговая запись получает средний уровень около −14 dBFS, цифровая — около −20 dBFS. Слух оценивает громкость по среднему уровню, поэтому копия с ленты звучит примерно на 6 дБ громче цифровой записи того же материала, хотя пики у них одинаковы. Кац называет это одной из причин, по которым продюсеры цифровых записей начали сжимать и ограничивать сигнал: иначе запись проигрывала по громкости аналоговым ([Katz, Level Practices, ч. 1](#sources)).

## Индикатор OVER {#over}

Пиковый измеритель цифрового магнитофона показывает наибольший модуль <Term id="sample" firstMention>отсчёта</Term>. Но отсчёт не может превысить полную шкалу, поэтому по одному отсчёту нельзя понять, был ли сигнал ровно на 0 dBFS или выше. При записи аналогового источника перегрузку видит <Term id="adc" firstMention>АЦП</Term>: если входное напряжение больше того, что соответствует 0 dBFS, все отсчёты на этом участке получают крайнее значение. На записи остаётся плоская вершина ([рисунок 1](#over-figure)).

<Term id="over" define>Индикатор OVER</Term> ищет такие вершины: он считает, сколько отсчётов подряд стоят на полной шкале. По Кацу, стандарт OVER для процессора Sony PCM-1630 — три отсчёта подряд: если три соседних отсчёта равны крайнему значению, аналоговый сигнал почти наверняка превышал 0 dBFS где-то между ними. Цифровые измерители позволяют выбрать и 4, 5 или 6 отсчётов, но Кац советует строгий порог в три ([Katz, Level Practices, ч. 1](#sources)). Процессоры серии 1600, к которой относится PCM-1630, записывали цифровой звук на видеокассеты U-matic, и с начала 1980-х на таких кассетах мастер отправляли на завод компакт-дисков ([Wikipedia, PCM adaptor](#sources)). То же правило «три и более отсчёта подряд на полной шкале» описано, например, в руководстве к интерфейсу Apogee Symphony I/O ([Apogee, Symphony I/O](#sources)). Документацию Sony, где задан порог PCM-1630, найти не удалось: число известно по описанию Каца.

<MarginNote items={[
  { label: 'Дискретизация → Период и частота дискретизации', description: 'Почему интервал между отсчётами равен 1/fs.', target: { article: 'sampling', anchor: 'sampling-period' } },
]}>

Длительность серии из $N$ отсчётов находится из <Term id="sampling-period" firstMention>периода дискретизации</Term>:

</MarginNote>

<Equation id="eq-run-duration" number={2}>

$$
t = N \cdot T_s = \frac{N}{f_s}
$$

<Fragment slot="symbols">
  <dt>$t$</dt><dd>длительность серии, с;</dd>
  <dt>$N$</dt><dd>число отсчётов в серии.</dd>
</Fragment>

</Equation>

При 44,1 кГц один отсчёт занимает около 22,7 мкс, а три — около 68 мкс. В тексте Каца для этого случая указаны 33 мкс; расчёт по [формуле (2)](#eq-run-duration) даёт примерно вдвое больше, поэтому здесь используется 68 мкс. Вывод от этого не меняется: Кац пишет, что искажение такой длительности большинство специалистов считают неслышимым, а строгий порог нужен, чтобы заметить все слышимые перегрузки ([Katz, Level Practices, ч. 1](#sources)).

### Пределы индикатора OVER {#over-limits}

<MarginNote items={[
  { label: 'Уровень сигнала → Истинный пик: dBTP', description: 'Как измеритель истинного пика оценивает волну между отсчётами.', target: { article: 'signal-level', anchor: 'true-peak' } },
  { label: 'Принцип работы лимитера → Пики между отсчётами', description: 'Пример с тоном fs/4, где отсчёты на 3 дБ ниже волны.', target: { article: 'limiter', anchor: 'true-peak' } },
]}>

Счётчик отсчётов проверяет только сами отсчёты. Восстановленная <Term id="dac" firstMention>ЦАП</Term> волна может подниматься между ними выше любого отсчёта, и сигнал, у которого ни один отсчёт не достигает полной шкалы, перегрузит ЦАП, преобразователь <Term id="sample-rate" firstMention>частоты дискретизации</Term> или кодер. Серии на полной шкале в таком сигнале нет, и OVER молчит. Поэтому счётчики отсчётов годятся для проверки перегрузки АЦП при записи, а для готовой фонограммы нужен измеритель <Term id="true-peak" firstMention>истинного пика</Term> ([ProSoundWeb, What Engineers Should Know About Meters](#sources)).

</MarginNote>

Кац указывает и другие ограничения. Стандарта для передачи признака OVER по цифровым интерфейсам AES/EBU и S/PDIF нет: если запись идёт с внешнего АЦП, индикатор рекордера показывает только уровень отсчётов. Перегрузка внутри цифрового процессора, например в <Term id="equalizer" firstMention>эквалайзере</Term>, может не дойти до выходного измерителя ([Katz, Level Practices, ч. 1](#sources)).

## Опорный уровень: 0 VU в dBFS {#reference-levels}

Когда пульт с VU-метрами соединяют с цифровым рекордером, нужно договориться, какой цифровой уровень соответствует 0 VU. Для этого подают синусоиду 1 кГц, выставляют её на 0 VU и смотрят показание пикового измерителя рекордера. Кац перечисляет три распространённых значения: −20, −18 и −14 dBFS ([Katz, Level Practices, ч. 1](#sources)).

<MarginNote items={[
  { label: 'Микширование → Запас уровня', description: 'Запас до предела конкретного участка тракта и его оценка по пику.', target: { article: 'mixing', anchor: 'headroom' } },
]}>

Расстояние от опорного уровня до 0 dBFS — это <Term id="headroom" firstMention>запас уровня</Term> для пиков, которые поднимаются над 0 VU. Он должен быть не меньше, чем пики выбранного материала превышают показание VU-метра. Иначе оператор, который держит стрелку около нуля, получит клиппинг в цифровой копии.

</MarginNote>

Например, при соглашении 0 VU = −18 dBFS дорожка, пики которой на 20 дБ выше показания VU-метра, достигнет $-18 + 20 = +2$ dBFS: два <Term id="decibel" firstMention>децибела</Term> будут срезаны. При −20 dBFS та же дорожка дойдёт ровно до 0 dBFS. Поэтому Кац выступает против −18 dBFS в студиях, которые пишут по VU-метрам ([Katz, Level Practices, ч. 1](#sources)). <Term id="ppm" firstMention>Квазипиковый измеритель</Term> реагирует медленнее цифрового пикового и занижает короткие пики. Для пульта с аналоговым PPM Кац предлагает запас 5 дБ: наибольшее показание PPM сопоставить с синусоидой −5 dBFS ([Katz, Level Practices, ч. 1](#sources)).

Вещательные организации закрепили такие соглашения в рекомендациях: EBU R68 задаёт для цифровой аппаратуры опорный уровень на 18 дБ ниже наибольшего кодируемого значения ([EBU R68-2000](#sources)).

## Пиковый уровень, VU и громкость {#meters-and-loudness}

<MarginNote items={[
  { label: 'Нормы громкости → Зачем нормировать громкость', description: 'Нормализация по пику и почему вещание перешло на LUFS.', target: { article: 'loudness-standards', anchor: 'why' } },
]}>

Пиковый измеритель защищает тракт, а о громкости говорит мало. Кац приводит пример: в первом дубле пики достигают −4 dBFS, во втором удар малого барабана доходит до 0 dBFS, а по громкости дубли примерно равны. Если поднять первый дубль на 4 дБ, чтобы пики совпали, он станет на 4 дБ громче второго ([Katz, Level Practices, ч. 1](#sources)). По той же причине <Term id="peak-normalization" firstMention>нормализация по пику</Term> выравнивает пики песен, но не их громкость.

</MarginNote>

<MarginNote items={[
  { label: 'Уровень сигнала → Громкость программы: LUFS', description: 'Взвешивание K, стробирование и окна 0,4 и 3 с.', target: { article: 'signal-level', anchor: 'loudness' } },
]}>

VU-метр усредняет уровень и потому ближе к слуху, но Кац перечисляет его недостатки ([Katz, Level Practices, ч. 2](#sources)). Одна постоянная времени 300 мс подобрана под речь и не моделирует слух. Шкала неравномерна: верхняя половина её длины отведена верхним 6 дБ, а весь полезный диапазон — около 13 дБ. Частотная характеристика ровная, хотя чувствительность слуха зависит от <Term id="frequency" firstMention>частоты</Term>: на музыке с сильным басом стрелка прыгает на несколько децибел, а слышимая громкость меняется меньше чем на 1 дБ. Эти два недостатка — отсутствие частотного взвешивания и одно окно усреднения — устраняет измерение громкости в <Term id="lufs" firstMention>LUFS</Term> по ITU-R BS.1770.

</MarginNote>

## K-система {#k-system}

Кац предложил связать шкалу измерителя с громкостью, которую инженер слышит из мониторов. В <Term id="k-system" define>K-системе</Term> 0 на шкале — не полная цифровая шкала, а опорный уровень, который в откалиброванной комнате даёт заданный <Term id="sound-pressure-level" firstMention>уровень звукового давления</Term>. Шкал три: K-20, K-14 и K-12, у них 0 лежит на 20, 14 или 12 дБ ниже полной шкалы. Верх каждой шкалы — 0 dBFS, поэтому запас для пиков над нулём равен 20, 14 или 12 дБ ([рисунок 2](#k-scales-figure)). Измеритель показывает два значения: средний уровень столбиком и последний наибольший пик отдельной меткой над ним ([Katz, Level Practices, ч. 2](#sources)).

### Калибровка монитора {#monitor-calibration}

Для шкалы K-20 Кац описывает такую калибровку. В один канал подают <Term id="pink-noise" firstMention>розовый шум</Term> с уровнем RMS −20 dBFS и выставляют усиление мониторов так, чтобы шумомер показал 83 дБ SPL с частотной коррекцией C и медленной реакцией. Каналы калибруют по одному. Для точности Кац советует узкополосный розовый шум 500–2000 Гц: широкополосный шум от 20 Гц до 20 кГц даёт ошибки из-за стоячих волн в комнате и направленности <Term id="microphone" firstMention>микрофона</Term> шумомера ([Katz, Level Practices, ч. 2](#sources)). Коррекция C, в отличие от A, слабо подавляет низкие частоты, а медленная реакция (Slow) — усреднение с постоянной времени 1 с ([Wikipedia, Sound level meter](#sources)).

На каждой шкале 0 соответствует тем же 83 дБ SPL. Значит, для K-14 и K-12 усиление мониторов меньше, чем для K-20, на 6 и 8 дБ: тот же уровень в комнате получается от сигнала на 6 и 8 дБ выше в dBFS. Связь показания шкалы с уровнем от одного громкоговорителя записывается [формулой (3)](#eq-k-spl).

<Equation id="eq-k-spl" number={3}>

$$
L_\text{SPL} \approx 83 + L_K, \qquad L_K = L_\text{ср} + N
$$

<Fragment slot="symbols">
  <dt>$L_\text{SPL}$</dt><dd>уровень звукового давления от одного громкоговорителя, дБ SPL;</dd>
  <dt>$L_K$</dt><dd>показание средней части шкалы K-N, дБ;</dd>
  <dt>$N$</dt><dd>номер шкалы: 20, 14 или 12.</dd>
</Fragment>

</Equation>

Формула описывает калибровку розовым шумом; для музыки она даёт ориентир, а не точное значение, потому что <Term id="spectrum" firstMention>спектр</Term> и пик-фактор материала отличаются от шума. Пример: монитор откалиброван для K-14, на вход подан розовый шум −20 dBFS. Показание $L_K = -20 + 14 = -6$ дБ, уровень в комнате около 77 дБ SPL. Это число совпадает с измерением Каца для поп-музыки ([Katz, Level Practices, ч. 2](#sources)). Две колонки вместе дают примерно на 3 дБ больше.

Условия калибровки в реализациях различаются. В обзоре <Term id="plugin" firstMention>плагина</Term> MeterPlugs K-Meter Хью Робджонс (Hugh Robjohns) называет опорный уровень 83 дБ C ([Sound On Sound, MeterPlugs K-Meter](#sources)), а справка FabFilter Pro-L 2 — 85 дБ SPL ([FabFilter, Pro-L 2: Metering](#sources)). Перед калибровкой стоит проверить, какой уровень, какой шум и какое соглашение об RMS приняты в конкретном измерителе.

Шкалу выбирают по материалу ([таблица 2](#k-scales-table)). Кац советует сводить по K-20, а при мастеринге решать с продюсером, оставаться на K-20 или переходить к K-14 ([Katz, Level Practices, ч. 2](#sources)). Робджонс в обзоре K-Meter распределяет шкалы так же: K-12 — вещание, K-14 — основная поп- и рок-музыка, K-20 — кино, классика и записи с широкой динамикой ([Sound On Sound, MeterPlugs K-Meter](#sources)).

Подъём выше нуля допустим. Оркестр без компрессии на fortissimo доходит до +3…+4 по средней шкале, а кульминации в роке звучат ненатурально, если их удерживать на 0. Но пользоваться этой зоной нужно изредка. По Кацу, если средний уровень постоянно в красной зоне, значит монитор откалиброван неверно, материал необычен по характеру или запись пережата ([Katz, Level Practices, ч. 2](#sources)).

<MarginNote items={[
  { label: 'Кривые равной громкости → Что это означает для музыки', description: 'Почему при тихом прослушивании бас кажется слабее.', target: { article: 'equal-loudness', anchor: 'music' } },
]}>

Смысл системы — в постоянном усилении мониторов. Кац наблюдал линейную связь: если уменьшить усиление мониторов на 2 дБ, инженер на слух поднимает средний уровень записи примерно на те же 2 дБ ([Katz, Level Practices, ч. 2](#sources)). Кто сводит с тихими мониторами, тот пережимает запись, чтобы она звучала достаточно громко. Калиброванное усиление снимает этот выбор: запись сводится до привычной громкости в комнате, а сколько места останется до 0 dBFS, задаёт шкала. Постоянное усиление полезно и из-за слуха: при разной громкости прослушивания меняется слышимый баланс низких и средних частот.

</MarginNote>

## 83 дБ SPL: опора из кино {#history}

Опорный уровень K-системы пришёл из кино. Кац пишет, что 83 дБ SPL на 0 VU аналоговой ленты предложил Айоан Аллен (Ioan Allen) из Dolby в середине 1970-х годов. Усиление громкоговорителей в кинозалах было стандартизовано, поэтому звук разных фильмов не отличался по громкости так, как музыка: по оценке Каца, громкость поп-музыки на разных компакт-дисках различалась на 10–12 дБ ([Katz, Level Practices, ч. 2](#sources)).

Как инженер мастеринга, Кац около 1993 года перешёл на регулятор громкости мониторов с шагом 1 дБ и стал записывать его положение для каждого проекта. Около 1994 года он поставил измерители Dorrough со шкалой, где 0 среднего уровня лежит на 14 дБ ниже полной шкалы: столько запаса над 0 VU давала аналоговая лента. В 1996 году он измерил усиление, при котором делал мастеринг большинства поп-альбомов, и оно оказалось на 6 дБ ниже кинематографического стандарта. При таком усилении 0 на шкале Dorrough давал те же 83 дБ SPL, что и в кино. Из этого сочетания выросла шкала K-14 ([Katz, Level Practices, ч. 2](#sources)).

<MarginNote items={[
  { label: 'Нормы громкости → Зачем нормировать громкость', description: 'Война громкости и выравнивание треков площадками.', target: { article: 'loudness-standards', anchor: 'why' } },
]}>

К концу 1990-х средний уровень компакт-дисков продолжал расти: Кац сравнивает рок-запись 1990 года и поп-сингл 1999 года, у которых пики одинаково достигают полной шкалы, а громкость различается более чем на 6 дБ. Он отмечает, что выше среднего уровня около −14 dBFS отдача падает: материал перестаёт казаться громче, потому что теряет ясность ([Katz, Level Practices, ч. 2](#sources)). K-система задумывалась как ответ на эту гонку: работа по шкале с постоянным мониторингом не даёт выигрыша от лишнего сжатия.

</MarginNote>

Статья с предложением K-системы вышла в сентябрьском номере Journal of the Audio Engineering Society за 2000 год: «An Integrated Approach to Metering, Monitoring, and Leveling Practices, Part 1: Two-Channel Metering». Версия на сайте Digido дополнена позже, в ней есть примечание от декабря 2007 года ([Katz, Level Practices, ч. 2](#sources)). Все статьи Digido помечены датой 6 апреля 2017 года, это дата переноса на новый сайт, а не первой публикации.

## K-система после BS.1770 и R 128 {#after-r128}

K-система — предложение одного автора, а не стандарт организации. Сам Кац называет её «предлагаемой» и надеялся, что она станет общим стандартом ([Katz, Level Practices, ч. 2](#sources)). Стандартом громкости стала другая разработка: алгоритм ITU-R BS.1770 с единицами LUFS, на котором построены рекомендация EBU R 128 и нормы стриминговых площадок ([нормы громкости](/loudness-standards/)).

<MarginNote items={[
  { label: 'Уровень сигнала → Взвешивание K', description: 'Какие фильтры BS.1770 применяет перед усреднением.', target: { article: 'signal-level', anchor: 'k-weighting' } },
  { label: 'Уровень сигнала → Стробирование и интегральная громкость', description: 'Как BS.1770 отбрасывает тихие блоки при расчёте громкости программы.', target: { article: 'signal-level', anchor: 'integrated-loudness' } },
]}>

По сравнению с BS.1770 устарели средняя и пиковая части измерителя. Средний уровень K-системы — RMS без частотного взвешивания и без <Term id="loudness-gating" firstMention>стробирования</Term>, с одним окном 600 мс; <Term id="integrated-loudness" firstMention>интегральной громкости</Term> всей программы он не даёт. Кац ещё в 2007 году ждал реализации с моделью громкости, а в тексте Digido упомянуты версии K-20/ITU, K-14/ITU и K-12/ITU с фильтрами BS.1770 ([Katz, Level Practices, ч. 2](#sources)). В плагине K-Meter такие режимы есть, но Робджонс отмечает, что это не полноценный измеритель громкости: нет интегральной громкости и стробирования ([Sound On Sound, MeterPlugs K-Meter](#sources)). Пиковая часть K-системы показывает наибольший отсчёт, а нормы громкости ограничивают истинный пик.

</MarginNote>

Сохранилась сама идея: 0 на шкале — опорная громкость, а запас до полной шкалы оставлен для пиков. В EBU R 128 между целевой громкостью −23 LUFS и пределом истинного пика −1 <Term id="dbtp" firstMention>dBTP</Term> 22 дБ; единицы другие, а устройство то же: громкость задана, и место над ней отдано пикам. FabFilter пишет, что R 128 теперь распространён шире, но K-система остаётся удобным способом регулировать уровни ([FabFilter, Pro-L 2: Metering](#sources)).

<Callout type="mistake" title="K-14 означает −14 LUFS">

<CalloutCase kind="wrong">

Мастер, который держится около 0 по шкале K-14, имеет громкость −14 LUFS и подходит под цель стриминговой площадки.

</CalloutCase>

<CalloutCase kind="right">

Число в названии шкалы — расстояние от её нуля до 0 dBFS. Шкала показывает RMS без взвешивания в окне 600 мс по соглашению AES-17, а LUFS — громкость с взвешиванием K, стробированием и усреднением по всей программе. Перевода одного в другое нет: для проверки под норму громкости нужен измеритель по BS.1770.

</CalloutCase>

</Callout>

## Самопроверка {#self-check}

<SelfCheck question="Индикатор OVER настроен на три отсчёта подряд. Сколько длится такая серия при частоте дискретизации 48 кГц и при 96 кГц?">

По [формуле (2)](#eq-run-duration): $3 / 48\,000 \approx 62{,}5$ мкс и $3 / 96\,000 \approx 31{,}3$ мкс. При той же настройке индикатор на 96 кГц срабатывает на вдвое более коротких перегрузках.

</SelfCheck>

<SelfCheck question="Студия выставила 0 VU = −14 dBFS и пишет по VU-метрам дорожки без обработки, пики которых на 18 дБ выше показания VU. Что произойдёт и какое соглашение подойдёт?">

Пики дойдут до $-14 + 18 = +4$ dBFS, то есть будут срезаны на 4 дБ. Запас должен быть не меньше 18 дБ: подойдёт −18 dBFS, а с учётом пиков до 20 дБ над 0 VU — −20 dBFS.

</SelfCheck>

<SelfCheck question="Монитор откалиброван для K-20. Включили мастер, сделанный по K-14: его средний уровень держится около −14 dBFS. Какое показание даст шкала K-20 и насколько громче мастер прозвучит по сравнению с материалом на 0 по K-20?">

На шкале K-20 показание $-14 + 20 = +6$ дБ, по [формуле (3)](#eq-k-spl) уровень около 89 дБ SPL от одного громкоговорителя. Мастер прозвучит примерно на 6 дБ громче, и средний уровень окажется в красной зоне шкалы K-20.

</SelfCheck>

<SelfCheck question="Почему счётчик отсчётов на полной шкале не заменяет измеритель истинного пика при выпуске мастера?">

Он видит только значения отсчётов. Восстановленная волна может подняться выше полной шкалы между отсчётами, которые сами ниже 0 dBFS; серии на полной шкале тогда нет, и OVER не срабатывает. Перегрузка проявится в ЦАП или кодере.

</SelfCheck>
